##how to run

travel agent 

CMD1 : php artisan serve --port=8080
CMD2 : npm run dev


##main uses
Laravel 11 – main PHP framework එක.
PHP 8.2+ – backend language එක.
MySQL – database එක.
Blade – Laravel frontend template engine එක.
HTML / CSS / JavaScript – page structure, styling, interactions.
Bootstrap – responsive UI design වලට.
Vite – frontend assets compile/run කරන්න.
Node.js + npm – frontend packages manage කරන්න.
Composer – PHP/Laravel packages manage කරන්න.
XAMPP – Apache + MySQL local server environment එක.
phpMyAdmin – database create/import/manage කරන්න.
Laravel Authentication – login, register වගේ user authentication.
MVC Architecture – Models, Views, Controllers විදිහට project structure කරලා තියෙනවා.
Laravel Routing – routes/web.php තුළ URLs/routes manage කරනවා.
Eloquent ORM – database tables එක්ක models හරහා වැඩ කරන්න.
Migrations / SQL – database structure create/manage කරන්න.
File Upload – payment receipt/images upload functionality.
